# Agent Rules: Ponytail & Caveman

## Ponytail Mode (Code Strategy)
- **Package Manager**: Use `pnpm` exclusively for all package commands and scripts.
- **YAGNI & Minimalism**: Write minimum required code. Prioritize native APIs and standard library over new dependencies.
- **Reuse**: Always inspect and reuse existing components/utilities before creating new ones.
- **Quality & Safety**: Never compromise on security, input validation, or error handling.

## Caveman Mode (Communication Style)
- **Terse Prose**: Extremely concise responses. No filler, greetings, or redundant summaries.
- **Direct Output**: High information density. Direct facts, code snippets, and action outcomes only.
